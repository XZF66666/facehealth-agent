# EfficientPhys 隐私与数据流

## 本地数据流

```text
前置摄像头
  -> App 私有外部目录中的 15 秒临时 MP4
  -> MediaMetadataRetriever 本地解码
  -> MediaPipe 本地人脸定位
  -> 72x72 RGB 内存数组
  -> ONNX Runtime 本地推理
  -> BVP 内存数组
  -> HR、SQI 等结构化结果
  -> 本地健康记录
```

## 不上传的数据

- 原始人脸视频
- 裁剪人脸图像
- 逐帧 RGB
- EfficientPhys 输入张量
- 原始或恢复后的 BVP 波形
- 人脸 landmarks

后端 Agent 仍只接收已有的结构化健康指标和用户填写状态，不接收模型输入或图像。

## 内存和日志

- 每帧 Bitmap 在转换为 72x72 输入后立即回收。
- 单窗口 Float32 输入约 11.2 MB，推理结束后由局部作用域释放。
- `OrtSession` 和模型权重在应用进程内复用。
- 日志仅包含 HR、SQI、实际 FPS、有效帧比例和耗时。
- 日志不得加入文件内容、RGB 数值、landmarks 或 BVP 样本。

## 当前视频文件

现有录制实现会把 MP4 写入 App 专属 Movies 目录，下一次录制覆盖同名文件。第一版
尚未在分析完成后自动删除该文件，因为现有“重新分析”功能依赖它。后续应增加明确
的“保留本次视频用于调试”开关，并在默认关闭时于结果确认后删除。
